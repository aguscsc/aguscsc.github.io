# aguscsc.github.io

Personal portfolio site. Plain HTML/CSS/JS, no build step — served directly by GitHub Pages from `main`.

## Structure

```
index.html                       Home — hero, featured projects, About (#about
                                  section), and side projects all on one page
contact.html
projects/index.html              Projects hub — all 4 categories + side projects
projects/quadruple-tank.html     Advanced Control
projects/dc-dc-converter.html    Power Electronics
projects/predictive-maintenance.html   Intelligent Monitoring
projects/robot-arm.html          Robotics
css/styles.css                   All styling (light "engineering notebook" theme,
                                  dark "blueprint" theme via prefers-color-scheme)
js/partials.js                   Shared header/footer + category icons, injected
                                  into every page's #site-header / #site-footer
assets/projects/                 Put project images here once you have them
assets/resume-es.pdf             Résumé (Spanish). Nav "Résumé" link and home
                                  hero button point at this path — update both
                                  in js/partials.js and index.html if you add
                                  an English version or rename the file.
```

All internal links use root-relative paths (e.g. `/contact.html`, `/css/styles.css`)
since this is a `username.github.io` site served from the domain root. That's
why local preview needs a server (see below) rather than double-clicking a file.

The About section lives inside `index.html` (id="about") rather than its own
page — the nav "About" link points to `/index.html#about`.

## Editing the nav

Header and footer are generated by `js/partials.js` from a single `NAV_ITEMS`
array — edit that one array to add/remove/rename a nav link everywhere at once.

## Adding a featured project (a new category)

1. Add a page under `projects/`, following the structure of an existing one
   (`.project-hero` block up top, then a `.subsection-list` if it has
   sub-parts, e.g. different techniques or sub-projects).
2. Add a matching card to the `.featured-grid` in `index.html` and
   `projects/index.html`.
3. Pick a category color/icon: `control`, `power`, `monitoring`, `robotics` are
   defined in `css/styles.css` (`--cat-*` variables) and `js/partials.js`
   (`ICONS`). Adding a 5th category means adding both.

## Adding a side project

Side projects are simple GitHub-linking cards — add a `.side-card` block to
the "Side projects" section in `index.html` and `projects/index.html`.

## Preview locally

Needs a local server (root-relative paths won't resolve over `file://`):

```
python3 -m http.server
```

Then open `http://localhost:8000`.
