Advanced Control

Quadruple Tank

In this project I developed the automatic control system for a 4-tank pilot plant — from the control logic to an ISA-101 compliant HMI in FactoryTalk View ME, communicating over OPC UA. I used the same coupled, nonlinear plant as a testbed to design and compare four control strategies: PID, feedforward, fuzzy logic, and MPC.

Control strategies

Four approaches, one plant.

PID

Classical proportional-integral-derivative control for setpoint tracking and disturbance rejection on the coupled tank levels.

Feedforward

Feedforward compensation added alongside feedback control to improve reference tracking and reduce loop interaction.

Fuzzy

A fuzzy logic controller encoding heuristic control rules as an alternative to model-based design.

MPC

Model predictive control optimizing future control moves over a receding horizon, subject to input and state constraints.
